## SailorSim on Windows: How to Install, Sail, and Fix Launch Issues

SailorSim has officially made the jump from Apple devices to Windows, and if you have ever wanted to learn the ropes of sailing without renting a boat or risking a capsize, this free simulator is the easiest entry point you will find. Built by a solo hobbyist developer (with a little help from AI-assisted coding), SailorSim lets you handle sails, manage the engine, and dock in and out of harbour—all rendered entirely in code. This guide walks you through installing it on Windows, setting up the assisted mode for total beginners, and troubleshooting the most common launch problems so you can get on the water fast.

## What SailorSim Actually Is (and What It Isn't)

Before you download, set your expectations correctly. SailorSim is **not** a AAA sailing game like *Sailwind* or *eSail*. It is a personal, non-commercial project focused on realistic fundamentals. Here is the quick breakdown:

| Feature | Details |
|---|---|
| **Price** | Free, non-commercial |
| **Platforms** | Windows (now), Steam (coming), Android (coming), iPhone/iPad/Mac (original) |
| **Developer** | Solo hobbyist, AI-assisted code |
| **Graphics** | Procedurally drawn (boat, sea, sails, scenery generated in code) |
| **Core gameplay** | Sail handling, engine control, harbour manoeuvres, navigation missions |
| **Beginner support** | In-game instructions + assisted mode |

Because the visuals are code-drawn rather than asset-based, do not expect photorealistic water. Expect a clean, functional sailing model that teaches you *why* a boat behaves the way it does.

## Step-by-Step: Installing SailorSim on Windows

1. **Get the official build.** Head to the developer's official distribution page (linked from the SailorSim project page). Avoid third-party "free download" mirrors—this is a small indie project and unofficial repacks are a malware risk.
2. **Check your system.** SailorSim is lightweight. Any Windows 10/11 machine with a modern integrated GPU (Intel UHD 620 or better) and 4GB RAM will run it. No dedicated graphics card required.
3. **Download the installer or portable build.** If a portable `.exe` is offered, prefer it—no registry changes, easy to remove.
4. **Run as administrator on first launch.** Right-click → *Run as administrator*. This prevents the most common "black screen on startup" issue caused by write-permission failures.
5. **Set your input.** Keyboard works out of the box. If you have a gamepad or joystick, plug it in *before* launching so the game detects it.
6. **Enable Assisted Mode.** On the main menu, toggle **Assisted Mode** on. This is essential for first-timers—it auto-trims sails and gives you on-screen prompts for each manoeuvre.

### First 10 Minutes: Your Learning Route

- **Lesson 1 – Engine only:** Motor out of harbour using throttle and rudder. Learn how slow a boat turns.
- **Lesson 2 – Raise sails:** Follow the in-game instruction prompts to hoist and trim.
- **Lesson 3 – Assisted docking:** Use assisted mode to enter harbour, then repeat with it off.
- **Lesson 4 – Navigation missions:** Complete the built-in missions to test points of sail (close-hauled, beam reach, running).

## Common Issues and Fixes

**Black screen or instant crash on launch**
Run as administrator (see step 4). If it persists, update your GPU drivers—procedural rendering leans on the graphics driver more than pre-baked assets do.

**Game not detecting a controller**
Launch the game *after* connecting the controller. Check Windows *Devices and Printers* to confirm it registers before starting SailorSim.

**Low frame rate**
Lower the render/sea detail setting in the options menu. Because the sea and scenery are drawn in code, reducing detail dramatically cuts GPU load. Also disable any overlay software (Discord, GeForce Experience) that hooks into the render pipeline.

**Sails won't respond**
Confirm you are not in Assisted Mode if you want manual control—assisted mode overrides trim inputs. Toggle it off in the main menu.

## Frequently Asked Questions (FAQ)

### Is SailorSim really free on Windows?
Yes. SailorSim is a free, non-commercial personal project. There is no paid tier or DLC.

### When is SailorSim coming to Steam and Android?
The developer has confirmed Steam and Android releases are planned following the Windows launch. Watch the official project page for dates—no firm release window has been announced yet.

### Can I learn real sailing from SailorSim?
It teaches genuine fundamentals—sail trim, points of sail, engine handling, and harbour manoeuvres—in assisted mode. It is a strong conceptual trainer, but it does not replace on-water instruction.

### Does SailorSim need a powerful PC?
No. It runs on modest hardware with integrated graphics. Lower the sea/render detail if you hit frame drops.
