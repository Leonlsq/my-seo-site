## Step-by-Step: Day-One Setup to Maximize Performance

The Legion 5i ships with Lenovo Vantage and Windows power plans that throttle performance out of the box. Do this immediately:

1. **Update everything first.** Open Lenovo Vantage → System Update, then run Windows Update and install the latest NVIDIA Game Ready driver directly from NVIDIA's site (skip the OEM driver).
2. **Enable Performance Mode.** In Lenovo Vantage → Power, select **Performance** (or press **Fn + Q** to cycle modes). This raises the GPU TGP and fan curve. Expect louder fans — that's normal.
3. **Set Windows to "Best Performance."** Settings → System → Power → Power mode → *Best performance*. Also disable "Power throttling" via the registry if you're chasing benchmarks.
4. **Turn on Hybrid Mode / Advanced Optimus.** In Vantage → Graphics, enable **Hybrid Mode** for battery life, or **Discrete GPU mode** for maximum gaming FPS (at the cost of battery).
5. **Enable DLSS 4 + Frame Generation in games.** In supported titles (Cyberpunk 2077, Alan Wake 2, Black Myth: Wukong), set DLSS to *Quality* and enable Multi Frame Generation for the biggest FPS gains.
6. **Cap refresh rate to 165Hz in NVIDIA Control Panel** and enable G-Sync to eliminate tearing.
7. **Undervolt the CPU** with Intel XTU (start at -50mV, test stability). This drops temps 5–8°C and reduces thermal throttling in long sessions.

## Common Issues, Thermals & What You Should Know

**Thermals are the real story.** The Legion 5i's cooling is good for its class, but the Core Ultra 9 275HX runs hot under sustained load. Expect CPU temps in the **85–95°C** range during heavy gaming — within spec, but use a laptop stand to improve airflow. GPU temps typically sit at **70–78°C**.

**Watch the RAM.** Some SKUs ship 32GB as 2×16GB (dual-channel, ideal) while others may use a single 32GB stick. Confirm dual-channel in Task Manager → Performance → Memory ("Slots used: 2"). Single-channel costs you 10–15% in CPU-bound games.
