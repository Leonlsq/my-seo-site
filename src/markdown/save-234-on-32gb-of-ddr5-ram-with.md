## Setup Checklist: Avoid the 5 Most Common AM5 Bundle Headaches

Bundles are great until you hit a boot loop. Follow this order:

1. **Flash the BIOS before first boot if needed.** The X870E Aorus Elite supports BIOS Flashback via USB — do this *before* installing the CPU if the board ships with an older AGESA. The 9800X3D needs a recent AGESA for stable boost behavior.
2. **Seat the RAM in slots A2/B2.** G.Skill DDR5-6000 kits are validated for the second and fourth slots from the CPU. Wrong slots = no EXPO stability.
3. **Enable EXPO, not XMP.** In BIOS, load the **EXPO profile** (not XMP) so the board applies the correct 6000 MT/s timings and 1:1 FCLK.
4. **Mount the MSI AIO with the pump below the radiator top.** Air bubbles at the pump are the #1 cause of "CPU overheating at idle" complaints. Route tubes so the pump isn't the highest point.
5. **Update chipset drivers and check the cooler's fan curve.** MSI's default AIO curve is conservative; set a custom curve in BIOS or MSI Center so the 9800X3D doesn't throttle under all-core loads.

### Quick BIOS settings worth changing
- **PBO:** leave on Auto unless you're chasing benchmarks; the 9800X3D is power-limited by design.
- **Curve Optimizer:** a mild **-15 to -20 all-core** offset lowers temps with negligible performance loss.
- **Memory Context Restore:** enable it to cut POST times on DDR5.
