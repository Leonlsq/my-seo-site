## How to Actually Search Hungary's Newly Released 60,000 Communist-Era Agent Files

Hungary has opened archives covering up to 60,000 former agents of its communist-era secret police (the ÁVH and later state security services), and the first thing most people do after reading the Euronews headline is ask: *can I search this myself, and how?* The short answer is yes — but the records are held by the **Historical Archives of the Hungarian State Security (ÁBTL)**, they are largely in Hungarian, and access is governed by Hungarian law, not a single global search box. This guide gives you the concrete path: where the files live, how to request or search them, what the 60k figure actually means, and the traps to avoid before you start naming people.

## Step-by-Step: Accessing and Searching the Released Files

The release is not a downloadable CSV dump. It is an expansion of archival access under Hungary's "glass-house" (üveg-ház) transparency model. Here is the practical workflow.

1. **Identify the correct archive.** The custodian is **ÁBTL (Állambiztonsági Szolgálatok Történeti Levéltára)** in Budapest. This is separate from the National Archives (MNL). If you search the wrong institution, you will find nothing and assume the files don't exist.
2. **Register as a researcher.** Most access requires a registration form (kutatási kérelem). Hungarian citizens and, in many cases, foreign researchers can apply. Bring/upload photo ID.
3. **Know your "status" under the law.** Access rules differ sharply depending on whether you are:
   - the **subject** of a file (the person surveilled),
   - a **relative** (often a spouse, child, or descendant),
   - a **researcher/journalist** (broader but still filtered access),
   - a **former agent** themselves.
4. **Search the finding aids (segédletek), not the raw documents.** ÁBTL maintains name indexes and "agent card" (ügynök-karton) registers. These are the entry points — you search a name, get a file reference (e.g., an "O-" or "B-" prefixed number), then request the dossier.
5. **Use the correct name variants.** Hungarian records use **birth name, married name, and code names**. A person may appear as "Kovács Istvánné," a code name like "Holló" (Raven), and a birth surname. Search all three.
6. **Submit a document request** for the specific file reference. Turnaround is typically weeks, not instant.
7. **Translate and cross-check.** Machine translation (DeepL handles Hungarian well) plus a second source is essential before you publish or share any claim.

### What the "60,000 agents" number actually covers

| Term | What it means | Why it matters |
|---|---|---|
| **Ügynök (agent)** | A registered informant/co-worker of state security | The headline "60k" refers to registered agents, not victims |
| **Hálózat (network)** | The full informant network | One person can appear in multiple files |
| **Karton** | Index card summarizing a person | Fastest first check before pulling full dossiers |
| **Dosszié** | The full case file | Where the detail and evidence live |
| **Üveg-ház** | The transparency/access framework | Governs who can see what, and when |

The 60k figure is a count of registered agents across the network — **not 60,000 separate searchable PDFs**. Expect to navigate indexes and request dossiers, not click through a finished database.

## Common Issues, Legal Traps, and What You Should Know

- **Name collisions are the #1 error.** Hungarian surnames like Nagy, Kovács, and Tóth are extremely common. A name match in an index is **not proof of collaboration**. Always confirm via file reference, dates, and location.
- **Code names mislead.** Agents operated under pseudonyms. Matching a code name to a real person requires the archive's internal cross-reference — do not guess.
- **The "agent vs. victim" confusion.** Many files describe people who were *surveilled*, not people who informed. Misreading this has caused real defamation cases. Check the document type before drawing conclusions.
- **Access is filtered, not fully open.** Hungary's framework protects certain personal data and ongoing legal categories. Some files remain restricted even after the release.
- **No official English interface.** Plan for Hungarian-language search terms. Useful terms: *ügynök* (agent), *besúgó* (informant), *megfigyelés* (surveillance), *kutatás* (research).
- **Verify before you share.** Cross-reference with academic historians or the archive's own staff. A single index hit is a lead, not a verdict.

### Alternatives if you can't access ÁBTL directly

- **Academic partners:** Hungarian universities and the Institute of History often hold parallel research access.
- **Journalists and NGOs:** Investigative outlets and transparency groups frequently publish vetted findings you can cite responsibly.
- **Published histories:** Secondary literature already maps major networks and is safer for context than raw, unverified index hits.

## Frequently Asked Questions (FAQ)

### Can anyone search Hungary's communist-era agent files online for free?
Not as a single free database. The files are held by ÁBTL, and access requires registration and, for full dossiers, a formal request. Some finding aids and published summaries are accessible, but there is no public one-click search of all 60,000 agent records.

### How many former agents were actually revealed in Hungary's release?
Reports cite **up to 60,000** registered agents in the state security network. This is a count of registered informants/co-workers, not 60,000 individually published dossiers, and it spans the communist-era state security apparatus.

### Is a name match in the files proof someone was an agent?
No. Hungarian names are highly collision-prone, agents used code names, and files also document *victims* of surveillance. A name in an index is a lead that must be confirmed through the specific file reference and document type before it means anything.

### Where are the Hungarian state security files kept?
At **ÁBTL**, the Historical Archives of the Hungarian State Security in Budapest — distinct from the National Archives (MNL). That is the institution to contact for research requests.

## Final Verdict

If you want to dig into Hungary's newly opened communist-era files, **start at ÁBTL, register as a researcher, and search the finding aids before requesting full dossiers** — and treat every name match as a lead, not a conclusion. The 60k-agent figure is real but easy to misread: it describes a registered network, not a finished, searchable public database. Do the cross-checking, respect the legal access rules, and you'll get accurate answers instead of defamatory guesses.
