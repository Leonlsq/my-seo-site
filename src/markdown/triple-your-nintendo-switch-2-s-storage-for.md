The Switch 2 is the first Nintendo console to require **microSD Express** cards for expandable storage. This is not a marketing gimmick — it's a hard compatibility requirement.

## How to Install and Format the Samsung P9 in Your Switch 2 (Step-by-Step)

1. **Power off the Switch 2 completely.** Hold the power button for 3 seconds and select *Power Options → Turn Off*. Do not use sleep mode.
2. **Open the kickstand.** The microSD Express slot sits behind the kickstand on the lower-left edge.
3. **Insert the card label-side up** until it clicks. It only fits one way — never force it.
4. **Power on the console.** A prompt appears: *"A microSD Express card has been inserted. Format it?"*
5. **Select Format.** This wipes the card and creates the Switch 2 file system. Formatting takes 10–30 seconds.
6. **Verify capacity.** Go to *System Settings → Data Management*. You should see ~476GB of free space.
7. **Set download destination (optional).** In *Data Management → Quick Settings*, choose "microSD Express Card" as the default so new games install there automatically.

### Move Existing Games to the New Card
If you already downloaded games to internal storage, you don't need to re-download them:
- Go to **System Settings → Data Management → Move Data Between Console/microSD Card**
- Select the games you want to relocate and confirm. A 30GB game moves in about 40 seconds.

## Frequently Asked Questions (FAQ)

### Does the Samsung P9 512GB microSD Express work on the original Switch?
No. The original Switch and Switch OLED use UHS-I microSD cards and cannot read Express cards. It is Switch 2 only.

### Is $99.99 actually a good price for a 512GB microSD Express card?
Yes. Street prices for 512GB Express cards hover around $140–150, so $99.99 represents a genuine 30%+ discount. It's the lowest recorded price for this capacity tier.

### Will a microSD Express card make Switch 2 games load faster?
Not noticeably. Internal storage and Express cards are both fast enough that load times are nearly identical. The benefit is **capacity**, not speed — though Express cards do speed up game installs and transfers versus UHS-I.

### Can I use the Samsung P9 in a Steam Deck or phone?
Only if the device explicitly supports microSD Express (PCIe). Most phones and the Steam Deck use UHS-I slots and will not recognize it.
