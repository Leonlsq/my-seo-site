## Cabernet PC Review: What Actually Makes It Good

Cabernet isn't a power-fantasy vampire sim. It's a narrative RPG where you play Liza, a young vampire navigating a 19th-century-inspired city, balancing humanity against hunger. The praise in that Reddit thread is earned for three reasons:

- **Writing and choice:** Dialogue trees carry real weight, and feeding choices affect relationships and endings.
- **Art direction:** A hand-painted, storybook aesthetic that holds up at high resolutions.
- **Pacing:** A slow-burn structure that rewards exploration over combat.

**The caveats:** there's no real-time combat loop, so if you want action, this isn't it. It's closer to a visual novel with RPG systems. On PC, the main friction points are performance stutter on mid-range hardware and controller mapping quirks — both fixable.

## Best Cabernet PC Settings to Fix Stutter and Boost FPS

Cabernet is not demanding, but Unity titles often ship with settings that cause frame-time spikes. Use this baseline, then adjust:

| Setting | Recommended | Why |
|---|---|---|
| Resolution | Native (1080p/1440p) | Upscaling adds shimmer to the hand-painted art |
| V-Sync | Off (use driver-level) | Reduces input lag; cap FPS instead |
| Frame Rate Cap | 60 or 120 (match monitor) | Prevents GPU overheating and stutter |
| Shadow Quality | Medium | High shadows cost the most FPS for little visual gain |
| Anti-Aliasing | FXAA or SMAA | TAA blurs fine line art |
| Texture Quality | High | Low VRAM impact; keep it high |
| Motion Blur | Off | Preference; off reduces nausea |
| Window Mode | Fullscreen | Borderless can cause alt-tab stutter |

**Step-by-step optimization:**

1. Launch the game once, then close it so a config file is generated.
2. Open your GPU control panel (NVIDIA Control Panel or AMD Adrenalin) and set **Max Frame Rate** to your monitor's refresh rate.
3. Enable **Low Latency Mode** (NVIDIA) or **Radeon Anti-Lag** (AMD).
4. In-game, apply the table above, then restart the game.
5. If stutter persists, verify game files via Steam (right-click Cabernet → Properties → Installed Files → Verify integrity).

## Common Cabernet PC Issues and How to Fix Them

**Controller not detected or wrong button prompts:**
- Plug the controller in *before* launching the game.
- In Steam, go to Settings → Controller and enable the correct input API (XInput for Xbox pads, Steam Input for DualSense).
- Disable Steam Input if you get double inputs.

**Black screen on launch / crash to desktop:**
- Update GPU drivers (a clean install via DDU if you've had issues).
- Add `-windowed` to launch options in Steam, launch once, then switch back to fullscreen.
- Ensure the game folder isn't in a OneDrive-synced path.

**Audio cutting out:**
- Set your default output device in Windows *before* launching.
- Disable spatial audio (Windows Sonic / Dolby Atmos) if crackling occurs.

**Save file concerns:** Back up your saves manually. The save path is typically under `%USERPROFILE%\AppData\LocalLow\Party Wagon Games\Cabernet`. Copy that folder before major updates.
