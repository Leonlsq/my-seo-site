**Key specs to verify before buying:**

## Step-by-Step: How to Use It for Your First PC Repair

1. **Match the bit to the fastener, not the other way around.** For a standard desktop build you'll mostly use PH2 (1/4") for case screws and PH0/PH00 (4mm) for motherboard standoffs. Never force a bit that doesn't seat fully — that's how you strip a head.
2. **Use the rigid extension for stubborn screws.** The flexible shaft flexes under torque and can cam out. Reserve it for recessed laptop screws where you can't reach straight on.
3. **Magnetize before you start.** Run the driver shaft through the magnetizer block a few times so screws stick to the tip — critical for M2 and M2.5 laptop screws.
4. **Pry with the spudger, not a flathead.** Using a metal flathead bit to open plastic clips gouges the chassis. The included plastic pry tools exist for exactly this.
5. **Organize by job, not by size.** Before a teardown, pull the 3–4 bits you'll need and set them aside. Digging through 120 bits mid-repair is how screws get lost.
6. **Clean and re-seat bits after use.** Wipe off metal shavings; a dirty bit won't seat fully and will strip heads.
