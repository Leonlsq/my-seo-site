### Step-by-Step: Optimize It on Day One

1. **Update the GPU driver first.** Install the latest NVIDIA Game Ready driver via the NVIDIA App, not Windows Update — OEM drivers lag by weeks and miss DLSS 4 profiles.
2. **Switch to "Performance" or "Overdrive" in Alienware Command Center.** The default "Balanced" profile caps the RTX 5070's power limit and can cost you 10–15% FPS.
3. **Enable MUX / discrete GPU mode.** In Command Center, set the display to dGPU-only to bypass Optimus and cut latency in competitive shooters.
4. **Set the display to its native refresh rate** in Windows Settings > Display > Advanced. Many units ship at 60Hz by default.
5. **Cap frame rates 3–5 FPS below refresh** (e.g., 162 FPS on a 165Hz panel) to reduce coil whine and thermals.
6. **Undervolt the CPU** via ThrottleStop or Intel XTU — a -80mV to -100mV offset typically drops temps 5–8°C with no performance loss.
7. **Elevate the rear** with a laptop stand to feed the intake fans; this alone can reduce GPU temps by 3–6°C.

## Common Issues, Alternatives & What You Should Know

**Thermals and noise:** An 18-inch chassis helps, but the RTX 5070 still pushes 100W+. Expect audible fan noise under load — this is a desktop replacement, not a silent ultrabook.

**Weight and battery:** Around 8+ lbs and 1–2 hours of unplugged gaming. Treat it as a portable desktop.

**Alternatives worth comparing:**
- **16-inch RTX 5070 laptops:** More portable, often $200–$400 cheaper, but smaller screens and tighter cooling.
- **RTX 5080 18-inch models:** ~15–20% faster, but rarely discounted this deeply — the $1,229 saving tips value toward the 5070.
- **Desktop + budget laptop combo:** Better raw performance per dollar if you don't need portability.

**Verify before buying:** Confirm the exact panel (refresh rate and brightness), warranty length, and whether the discount applies to the 32GB config specifically — retailers sometimes discount a lower-spec SKU.
