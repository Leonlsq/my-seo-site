## Recommended Settings for the Demo (PC Optimization Guide)

Retro-styled 3D games often ship with aggressive post-processing (CRT filters, film grain, chromatic aberration) that looks great in trailers and hurts readability in play. Use this baseline:

1. **Resolution:** Native, always. Retro games upscale poorly with in-game scalers — use your GPU's integer scaling if the demo supports it.
2. **Film grain / CRT filter:** Start at 50%, drop to 0% if you're hunting for small clues. Grain hides interactable objects.
3. **Motion blur:** Off. Non-negotiable in a game where you're scanning dark corners for threats.
4. **Field of view:** Max out if adjustable. Survival horror tunnel vision is intentional, but a wider FOV reduces motion sickness in tight corridors.
5. **Mouse sensitivity:** Lower than your FPS default. Puzzle interaction and item pickup precision matter more than flick shots.
6. **Brightness:** Calibrate in the first dark room, not the menu. You want enemies *barely* visible, not invisible.

### Survival Strategy: The Three-Rule System

- **Rule 1 — Scout before you commit.** Every level has multiple paths. Walk the perimeter of each room before touching anything.
- **Rule 2 — Ammo is a key, not a weapon.** If a fight can be avoided by backtracking, backtrack. Save rounds for scripted chokepoints.
- **Rule 3 — Write clues down.** External notes (or screenshots) beat an in-game journal that may not exist in the demo build.
